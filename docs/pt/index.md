# netbox-cli

[English](../index.md)

CLI em Python para consultar e administrar inventário físico no NetBox, com menus,
tabelas e árvores para uso humano e JSON para scripts, pipelines e agentes de IA.

## Comece por aqui

1. [Instale a CLI e faça a primeira consulta](getting-started.md).
2. [Configure a conexão, autenticação e formatos de saída](configuration.md).
3. [Explore inventário, árvores, capacidade e conexões](operations.md).
4. [Consulte os comandos de cada recurso](reference.md).
5. [Automatize com idempotência e dry-run](automation.md).

## Recursos

Regiões, sites, locais, grupos de racks, racks, fabricantes, funções e tipos de
dispositivos, dispositivos, interfaces, portas frontais, traseiras, de console e
energia, além de cabos. A CLI também oferece busca, inspeção, exportação de
inventário, elevação de racks e rastreamento físico.
