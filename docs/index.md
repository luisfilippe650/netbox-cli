# netbox-cli

[Português](pt/index.md)

A Python CLI for querying and managing physical inventory in NetBox. Interactive
menus, tables and trees support human operators; JSON supports scripts, pipelines
and AI agents.

## Start here

1. [Install the CLI and run your first query](getting-started.md).
2. [Configure connectivity, authentication and output](configuration.md).
3. [Explore inventory, trees, capacity and connections](operations.md).
4. [Find resource commands](reference.md).
5. [Automate with idempotency and dry-run](automation.md).

## Resources

Regions, sites, locations, rack groups, racks, manufacturers, device roles and
types, devices, interfaces, front, rear, console and power ports, and cables.
Search, inspection, inventory exports, rack elevation and physical tracing are
also available.
